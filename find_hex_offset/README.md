查找文件中特定十六进制序列的偏移。

比如有一个数据头具有固定格式，通过`hexdump`看到：
```
# hexdump -s 0x608 -n 0x30 perf.data
0000608 0047 0000 0000 0030 3720 0001 0000 0000
0000618 0000 0000 0000 0000 05a5 41f0 0004 0000
0000628 0001 0000 0168 0000 0001 0000 0000 0000
```

考虑到小端模式，实际前8个数据为：`4700 0000 0000 3000`，则：
```
# python3 find_hex_offset.py perf.data "4700 0000 0000 3000"
正在查找文件 'perf.data' 中的十六进制序列 '4700 0000 0000 3000' 的偏移...
找到 6 个匹配项：
偏移: 0x00000608
偏移: 0x00013E18
偏移: 0x001BDEB8
偏移: 0x001C20C8
偏移: 0x001FD6C0
偏移: 0x003ED818
```
